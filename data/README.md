# Data

This project uses the **UCI Online Retail II** transaction dataset. The raw dataset is intentionally not committed to this repository.

The analytical period runs from December 1, 2009 through December 9, 2010. December 2010 is a partial month and is treated accordingly in monthly comparisons.

Core source fields include Invoice, StockCode, Description, Quantity, InvoiceDate, Price, Customer ID, and Country. Revenue is derived as Quantity × Price.

To reproduce the notebook, obtain the source Online Retail II workbook and upload it when prompted in Phase 1.
